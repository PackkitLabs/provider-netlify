Decouple from the JavaScript generator. The provider consumes the provider-neutral **`@packkit/core`** deployment contract, not `create-packkit` — support is `provider × DeploymentContract`, not `provider × language`, so a static site generated by create-packkit, create-packkit-py, or any future generator is handled the same. Dropped the stale `create-packkit` peer dependency (`^3.3.0`, wrong direction), added `@packkit/core` (its `DeploymentType` types the supported set), and fixed the dead `danmat.github.io` schema URL.
